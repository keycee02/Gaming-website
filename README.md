# Activity 01: ALL OR NOTHING — NEXUS ARENA (Gaming Website)

A responsive gaming community and game showcase website built strictly with **HTML5 and CSS3** (zero JavaScript) and deployed on GitHub Pages.

## Pure CSS Features Used
- **Responsive Mobile Navigation**: Checkbox hack (`#menu-toggle:checked ~ .nav-links`)
- **Interactive Game Spec Modals**: CSS `:target` pseudo-class overlays in `gallery.html`
- **Native FAQ Accordions**: Semantic HTML5 `<details>` and `<summary>` elements in `about.html`
